# 📚 Сәйкестендіру тесті - Студенттерге арналған

Ақпараттық қауіпсіздік бойынша сәйкестендіру тесті. Next.js және Supabase қолданылған.

## 🚀 Орнату

1. Тәуелділіктерді орнату:
```bash
npm install
```

2. Supabase жобасын құру:
   - [supabase.com](https://supabase.com) сайтына кіріңіз
   - Жаңа жоба құрыңыз
   - SQL Editor-да төмендегі кодты орындаңыз:

```sql
CREATE TABLE student_answers (
  id BIGSERIAL PRIMARY KEY,
  student_name TEXT NOT NULL,
  answers JSONB NOT NULL,
  score INTEGER NOT NULL,
  grade INTEGER NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- RLS (Row Level Security) өшіру (тестілеу үшін)
ALTER TABLE student_answers DISABLE ROW LEVEL SECURITY;
```

3. `.env.local` файлын құру:
```bash
cp .env.local.example .env.local
```

4. `.env.local` файлына Supabase деректерін қосу:
   - Project Settings → API бөліміне өтіңіз
   - `NEXT_PUBLIC_SUPABASE_URL` және `NEXT_PUBLIC_SUPABASE_ANON_KEY` көшіріңіз

5. Жобаны іске қосу:
```bash
npm run dev
```

6. Браузерде ашу: [http://localhost:3000](http://localhost:3000)

## 📖 Қалай пайдалану

### Студент беті (/)
1. Аты-жөніңізді енгізіңіз
2. Әр ұғымға сәйкес сипаттаманы таңдаңыз
3. "Жауаптарды сақтау" батырмасын басыңыз
4. Нәтижеңізді көріңіз

### Оқытушы беті (/teacher)
1. Барлық студенттердің нәтижелерін көру
2. Бағалар бойынша фильтрлеу (3, 4, 5)
3. Статистиканы көру

## 🎯 Бағалау жүйесі

- 5-6 дұрыс жауап = Баға 5
- 4 дұрыс жауап = Баға 4
- 0-3 дұрыс жауап = Баға 3

## 🎨 Дизайн

- Ашық түсті, заманауи дизайн
- Қазақ тілінде интерфейс
- Responsive дизайн (барлық құрылғыларда жұмыс істейді)
